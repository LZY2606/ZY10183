# 频弧辨证台

电化学阻抗谱（EIS）的同一组有限频段数据，往往能被多个结构不同的等效电路解释出几乎重合的
Nyquist 弧。本工具用于**辨证**这些候选：在受限的 R / C / L / CPE / Warburg 网络上做多起点加权拟合，
并排保留每个起点的解，报告参数可辨识性（设计矩阵秩、条件数、相关、零空间方向），并以父子版本保留
“固定参数 / 修改权重后重跑”的完整轨迹。

## 安装与演示

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 5523
```

浏览器访问 <http://127.0.0.1:5523>，页面顶部应显示 **频弧辨证台**。

删除该文件后重启服务会自动重建内置 fixture。

## 数据口径（约定明文）

### 阻抗约定

* 时间因子统一取 **e^(+jωt)**，因此无源阻抗满足 `Im(Z) < 0`；Nyquist 图按 EIS 习惯以 `-Im(Z)` 为纵轴向上。
* 电容：`Z_C = 1/(jωC)`；电感：`Z_L = jωL`。
* CPE：`Z_Q = 1/[Q (jω)^n]`，其中复幂取 **主值支**：`(jω)^n = ω^n · exp(+j·nπ/2)`；
  `n=1` 退化为理想电容。**CPE 指数 n 的物理上下界恒为 [0, 1]**，任何参数定义的界必须包含在其中。
* Warburg（半无限扩散）：`Z_W = 1/[W·√(jω)] = (1−j)/(W·√(2ω))`，W 为导纳系数，单位 S·s^0.5。
* 频率一律以 **Hz** 输入，内部换算 `ω = 2πf`。

### 表达式（稳定序列化）

```
top  := node ("," node)*        # 顶层逗号即串联
node := ("s"|"p") "(" node ("," node)* ")" | element
element := "r"|"c"|"l"|"w"|"cpe" [":" 标签]
```

* `s(...)` 串联、`p(...)` 并联；同级同类组合在规范序列化时展平，标签与元件名统一小写，
  无空白。例如输入 `R, P(R:CT, CPE:DL)` 规范化为 `s(r,p(r:ct,cpe:dl))`。
* 同类元件出现多次时必须带标签（`r:ct`、`r:b`）；参数键形如 `R:ct`、`Q:dl`。
* 每个参数带单位、下界、上界、初值与**可选共享组**；共享组只允许同单位参数，
  拟合时取各成员界的交集、只保留一个自由变量。

### 数据文件

CSV/TSV，列 `freq_hz,zreal,zimag`（也接受 `f/re/im`、中文表头等别名，可带表头，行号从 1 计）。

* **只有正且有限的频率进入对数轴与拟合。**
* `freq <= 0` 或无法解析的行被剔除，但导入结果与界面会逐条给出**原始行号与原因**。

### 拟合与权重

* 残差向量 `r = √w · [ΔRe; ΔIm]`（先实后虚），最小化加权 SSE。
* 权重模式：`unit`（等权）、`modulus`（`w=1/|Z|²`，默认）、`sigma`（逐点 `1/σ²`）。
* 可选频率权重乘子 `w ← w · (f/f_ref)^(2γ)`（`f_ref` 默认取几何中心）。修改 γ 后重跑会生成
  带 `parent_id` 的子版本，父版本原样保留，可在“运行版本树”中追溯。
* 正物理量（R/C/L/Q/W）在**对数内部空间**优化，n 在线性空间优化；多起点在盒内用确定性
  随机种子（默认 1186）撒点，求解器为投影式 Levenberg–Marquardt（仅 NumPy 实现）。
* 固定参数通过把该参数界收缩为单点实现，重跑后以子版本保存。

### “贴上界”不是“收敛”，近秩亏不给伪精密标准误

每次多起点拟合分别给出终止原因：

* `converged`：活动方向梯度足够小，参数在界内（或 KKT 意义下）真正收敛；
* `at_bound`：存在参数贴在界上、且界方向仍有显著“想越界”的梯度——**是被界挡住，不是数值收敛**；
* `max_iter`：达到迭代上限仍有可观移动。

解点处对设计矩阵 J（列取**物理参数直接灵敏度** `∂r/∂p`）做 SVD：

* 报告机器精度秩、条件数与全部奇异值；
* 条件数 > `1e8` 即判为“形式满秩、实际近秩亏”，此时 **Gauss–Newton 标准误会被噪声放大，
  系统拒绝给出标准误与相关矩阵**，只报告弱/零参数方向（哪些参数怎么一起变，拟合几乎不响应）。

## 内置固定 fixture

数据集由真值电路 `s(r,p(r:ct,cpe:dl))`（Rs=10 Ω, Rct=200 Ω, Q=2e-5, n=0.88）在
1 Hz–10 kHz、25 个对数频点合成，固定随机种子 1186 加 0.5% 比例噪声；CSV 开头插入
`f=0`、`f=-10` 两行用于验证剔除与行号报告。三个候选：

| 候选 | 表达式 | 验收点 |
|---|---|---|
| A | `s(r,p(r:c,c))` | 与真值在观测带内近等价；内部真正收敛、给标准误 |
| B | `s(r,p(r:c,cpe:dl))`，n 上界压到 0.75 | 最优解 n **只贴上界**，终止原因 `at_bound` |
| C | `s(r,r:b,p(r:ct,cpe:dl))` | Rs/Rb 各自不可辨识、只有其和可辨识；条件数 ≫1e8，**不给标准误**，零空间方向 `[+R, −R:b]` |

A 与 B 的加权 SSE 都在约 0.27–0.30，Nyquist 弧几乎重合，但参数化不同；这正是“频弧辨证”的对象。

## 操作流程

1. ① 选择数据集（或上传自己的 CSV，查看被剔除行号）。
2. ② 选择/编辑候选电路：改表达式后点“校验/补全参数”，编辑每个参数的单位、界、初值与共享组，保存。
3. ③ 选权重模式、γ、起点数后“多起点拟合”；勾选参数可固定后重跑（子版本），或一键用 γ=0.5 重跑。
4. 右侧标签页：**Nyquist / 幅相图（|Z| 与 φ）/ 加权残差 / 多起点并排 / 参数与相关 / 秩亏诊断**。
5. ④ 版本树按父子关系列出全部运行，点击即回看。
6. 顶栏“导出运行记录”下载整库 JSON；“清空并重置”或清空后用“导入复核”重放。

## 导出 / 清空 / 导入复核

* `GET /api/export` 导出格式 `pinpai-tai/v1` 的整库 JSON（数据集、电路、全部运行含完整结果）。
* `POST /api/import` 按**原主键**整体替换：清空后导入可逐 ID 复现历史运行。
* `POST /api/reset` 清空并恢复内置 fixture。
* 命令行重放示例：

```bash
curl -s http://127.0.0.1:5523/api/export -o runs.json
curl -s -X POST http://127.0.0.1:5523/api/reset   # 清空
curl -s -X POST http://127.0.0.1:5523/api/import -H 'Content-Type: application/json' \
     --data @runs.json                            # 重新导入复核
```
